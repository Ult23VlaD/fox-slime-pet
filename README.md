# Фокси-слайм — настольный питомец для Kimi Work

Настольный питомец (desktop pet): оранжево-чёрный слайм с лисьей мордочкой.
Версия одна — спрайтовая (2D). Это выбранная владельцем модель («Моя»).
3D-варианты существовали в истории проекта, но удалены по решению владельца
(2026-11-01): не предлагать и не восстанавливать, пока владелец сам не попросит.

## Структура

- `pets/fox-slime/` — пакет питомца (pet.json + spritesheet.png),
  8 состояний: idle, working, waiting, failed, running_left/right, idle_random_1/2.
- `assets/` — референсы: master-reference.png (одобренный 2D-референс),
  reference-want.jpg (образец, присланный владельцем).

## Установка

Через Kimi Work: `Widget.installPet` с `packagePath` на папку пакета
(`pets/fox-slime`). id питомца: `fox-slime` — переустановка обновляет
существующий виджет.

## Рабочий процесс

Все изменения делаются локально в этой папке, проверяются, и только после
подтверждения владельца выгружаются на GitHub.
